# Sample Resume and Job Description Dataset

A small sample dataset containing resumes and job descriptions for
practicing resume matching and keyword analysis functions.

## Usage

``` r
resume_sample_data
```

## Format

A data frame with 3 rows and 4 variables:

- candidate_name:

  Name of the candidate

- target_role:

  Target job role

- resume_text:

  Resume text for the candidate

- job_description:

  Sample job description text

## Source

Simulated data created for educational purposes.
